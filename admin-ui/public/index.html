◆Zero-Trust IAPAdmin Console
Zero Trust operations console

Security dashboard

Manage policies, inspect live access decisions, replay risk scenarios and monitor certificate lifecycle from one local control plane.

How to use
  1. Enter the admin token and select Save.
  2. Use Policies to review or edit access rules.
  3. Use Access Logs to inspect LIVE, SIMULATION and SYSTEM events.
  4. Use Security Lab to replay deterministic risk scenarios.
  5. Use Cert Rotation to inspect lifecycle status and rotate when Vault PKI is configured.
Protected application

The demo upstream is available through the IAP at https://localhost:8443/dashboard. The Admin Console itself runs on http://127.0.0.1:8444.
