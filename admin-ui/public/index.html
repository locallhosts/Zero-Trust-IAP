How to use

  1. Enter the admin token and select Save.
  2. Use Policies to review or edit access rules.
  3. Use Access Logs to inspect real and simulated decisions.
  4. Use Security Lab to replay deterministic risk scenarios.
  5. Use Cert Rotation to inspect lifecycle status and Vault rotation.
